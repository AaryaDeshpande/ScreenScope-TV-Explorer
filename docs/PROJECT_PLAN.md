# ScreenScope Scope

The project has two required pages:

1. **Search:** Search TMDB, select one movie or TV show, and view its details.
2. **Explorer:** Filter by media type, genre, and year, then show pandas summary
   values, a table, and two Matplotlib charts.

The assignment table and build order in the main [README](../README.md) are the
source of truth. Accounts, watchlists, recommendations, machine learning, a
database, and additional APIs are outside the project scope.
